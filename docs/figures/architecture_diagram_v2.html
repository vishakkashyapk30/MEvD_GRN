New at the training level (not part of the per-example forward pass above): a shared copy of this model can now be trained JOINTLY across more than one cell type at once (scripts/12_joint_train.py: K562 + MCF7, alternating gradient steps, each keeping its own graph/features), then evaluated zero-shot on a THIRD, held-out cell type (Macrophage) it never saw during that run — reaching AUPR 0.74–0.70 vs. a 0.84 from-scratch ceiling, far above single-cell-type transfer (0.61 / 0.45). This is the strongest generalization result found so far.
Ablation hooks
• integration="gated"/"concat" → legacy fused-embedding + bilinear decoder
• use_atac=False → RNA-only
• use_gnn=False → encoders feed the decoder directly
• use_fm=True → adds the Geneformer branch
• combine_mode="gated" → learned relation weights
Curriculum training
Default: Stage 1 Localization (lr 1e-3, 30ep) →
Stage 2 Perturbation (lr 3e-4, 15ep, + replay)
Dual-Evidence = held-out zero-shot tier
(all_at_once joint-tier training is available but NOT the default — it loses on the metrics that matter, see results.md)
What actually helped (2026-09-11 ablations)
• RP-weighted ATAC: real, consistent gain (was ~0)
• Geneformer embedding: single biggest in-domain gain
• Joint multi-cell-type training: single biggest transfer gain
• gated relation combiner: neutral so far (needs the motif graph to matter)
Honest caveat
The Geneformer embedding, when trained on ONE cell type only, makes cross-cell-type transfer WORSE, not better — fixed (mostly) by joint multi-cell-type training. See results.md Section on foundation-model embeddings.
